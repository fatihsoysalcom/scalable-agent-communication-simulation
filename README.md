# Scalable Agent Communication Simulation

This Python script simulates a multi-agent system where agents communicate by sending messages. It demonstrates potential scaling issues like message loss and increased processing time as the number of agents grows, reflecting challenges in real-world distributed MAS.

## Language

`python`

## How to Run

Run the script using: python main.py
Increase NUM_AGENTS to observe scaling problems.
